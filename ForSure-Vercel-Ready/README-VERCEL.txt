FORSURE COURTS — VERCEL DEPLOYMENT

This is a static HTML/CSS/JavaScript prototype. It does not need a build command, framework preset, or backend.

IMPORTANT:
- The project root must be the folder containing index.html, css/, and js/.
- This ZIP is already arranged that way (index.html is at the ZIP root).
- In Vercel, import the repository or upload/deploy this folder.
- Framework Preset: Other
- Root Directory: ./ (the folder containing index.html)
- Build Command: leave empty / no build command
- Output Directory: leave empty / default (or use . if the dashboard requires a value)
- Install Command: leave empty

After deployment, open the generated .vercel.app URL.

Open Play prototype data is stored in localStorage in each browser. It is not shared across different users/devices. Deploying to Vercel does not add a database or backend.
